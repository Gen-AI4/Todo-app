## Phase 1: Design & Architecture

### Data Model Design

#### Task Entity
```
Task:
  - id: int (unique identifier)
  - title: str (task description)
  - description: str (optional detailed description)
  - status: str (pending/completed)
  - priority: PriorityEnum (High/Medium/Low)
  - tags: List[str] (list of category tags)
  - due_date: Optional[datetime] (optional due date)
  - created_at: datetime (timestamp of creation)
  - completed_at: Optional[datetime] (timestamp of completion)
```

#### Priority Enum
```
PriorityEnum:
  - HIGH = "high"
  - MEDIUM = "medium"
  - LOW = "low"
```

#### Filter Criteria
```
FilterCriteria:
  - status: Optional[str]
  - priority: Optional[PriorityEnum]
  - tags: Optional[List[str]]
  - search_term: Optional[str]
  - due_date: Optional[datetime]
```

### API Contract Design

#### Command Line Interface

**Add Command Extension:**
```
add "TASK_TITLE" [OPTIONS]
  --priority, -p: Priority level (high|medium|low)
  --tag, -t: Tag for the task (can be used multiple times)
  --due-date, -d: Due date for the task (YYYY-MM-DD format)
```

**List Command Extension:**
```
list [OPTIONS]
  --status: Filter by status (pending|completed)
  --priority: Filter by priority (high|medium|low)
  --tag: Filter by tag
  --search: Search term for filtering
  --sort: Sort by (date|priority|alpha)
  --all: Show all tasks (including completed)
```
